# Ke Ma — Personal Website

Source for the academic and personal website of Ke (Mark) Ma.

A bilingual academic and personal website built with Quarto and a custom, dependency-light visual system.

## Local development

```bash
quarto preview
```

Create a complete production render:

```bash
quarto render
```

Generated output is written to `_site/` and is not committed.

## Publication boundary

Local changes are reviewed before any commit or push. Publishing the site requires explicit approval from the repository owner.
